# 发条回响 · Clockwork Echoes

时间回环解谜。你是钟楼里一个上了发条的小铜人，发条只够走几步。走完了时间就倒流回起点，你再上一次弦，而上一轮的你会变成青色的「回响」，把你按过的每一个键原样重演一遍。你要和过去的自己配合：一个人踩住圆盘，另一个人穿过门；一个人去推箱子，另一个人去引开巡逻机。任何一个你走到钟面上，就算过了这一层。

**在线试玩：<https://wowayou.github.io/clockwork-echoes/>**（手机、电脑都可以；推送到 main 会自动发布）

一共十二层，对应钟面的十二个时辰，分三章：

| 章 | 层 | 新东西 |
|---|---|---|
| 上弦 | I–IV | 圆盘和门、收束本轮、三个你、让一个回响先后做两件事 |
| 齿合 | V–VIII | 回响重演的是**按键**：门关着时往里走，下一轮有人开门它就真的走进去；卡门、木箱、反向门 |
| 擒纵 | IX–XII | 巡逻机：躲开它、让过去的你当替身、用箱子护住过去的你，最后三个你一起敲响钟 |

TypeScript + Canvas 2D + Web Audio，**没有运行时依赖**，构建产物约 25 KB JS（gzip）。声音全部实时合成，没有音频文件。

## 怎么玩

| 操作 | 键盘 | 手机 |
|---|---|---|
| 走一步 | 方向键 / WASD | 在棋盘上滑动，或用方向键盘 |
| 原地等一拍 | 空格 | 方向键盘中间的「等」 |
| 收束本轮（剩下的时间原地站着） | 回车 / E | 「收束本轮」 |
| 撤销（可以跨轮，没有次数限制） | Z / Backspace | 「撤销」 |
| 从头再来（也能撤销） | R | 「重来」 |
| 提示 / 规则图例 / 返回 | H / ? / Esc | 横幅里的「提示」、右上角 ? 、左上角返回 |

界面上帮你看清因果的几样东西：

- **虚线预告**：如果你原地不动，过去的你和巡逻机接下来会去哪里。你踩上圆盘、推开箱子，虚线会立刻跟着变；红色 × 表示那个回响会在那里被抓住。
- **粉色**：你的所作所为改变了某个回响原本的路线。灰色虚线是它原本的路。
- **时间轴**：每一行是一个你，每一格是那一拍按下的键。下划线表示那一下被挡住了，× 表示被抓住。鼠标悬停（手机上长按）某一拍，棋盘会显示那一刻的样子。

卡住了可以看提示，也可以看参考解法的演示，看过之后下一层会解锁。

## 开发

```bash
npm install
npm run dev          # 本地开发
npm run check        # 类型检查 + 单元测试 + 构建
npm run solve -- all # 用求解器检查每一层（见 docs/LEVEL-FORMAT.md）
npm run build && node tools/shots.mjs shots   # 在本机 Chromium 里实测并截图
```

`tools/shots.mjs` 用 Chrome 调试协议驱动生产构建，不依赖任何 npm 包。它在手机竖屏（390×844，触控）和桌面（1280×800，键盘）上各跑一遍，覆盖的内容有：

- 用真实按键和触控玩通若干层，包括时间倒流、回响改道、被抓后时间自动走完、跨轮撤销、悬停预览，以及帮助、设置和参考解演示；
- 桌面端用真实按键把十二层的参考解全部打一遍；
- 检查页面没有横向滚动、棋盘能放进舞台、控制台没有报错。

运行前需要本机有 Playwright 自带的 Chromium，路径可以用 `CHROME=` 环境变量指定。

### 正确性怎么保证

- **规则是纯函数**（`src/game/engine.ts`）：给定所有的你按下的键，世界的状态是唯一确定的。撤销、重来、回响重演、预告虚线、参考解演示都只是按同一份规则重新算一遍，不会出现前后对不上的情况。
- **每一层都被证明过**（`tests/levels.test.ts`）：参考解在真实规则下能过关，并且用的人数正好等于金齿轮要求的人数；对每个更少的人数，求解器会穷举所有的你的全部按键组合，确认都无解。
- **规则的边界情况有单元测试**（`tests/engine.test.ts`）：卡门、反向门、箱子推不动的各种情况、巡逻机对穿时抓人、只抓最早的那个你、被抓后快进、跨轮撤销。
- **音量是测出来的**：`__ce.audio()` 用 OfflineAudioContext 离线渲染每个音效，测量峰值、RMS，以及 500 Hz 以上的能量（手机扬声器能放出的部分）。

## 结构

```
src/game/engine.ts    规则（地图解析、一拍的结算）
src/game/session.ts   一局的状态：各轮按键、撤销、收束、预告
src/game/solver.ts    联合广度优先搜索
src/game/levels.ts    十二层
src/render/board.ts   棋盘渲染（3/4 视角、预告虚线、粒子）
src/render/bg.ts      背景齿轮（每拍转一齿，倒流时倒转）
src/audio/sfx.ts      合成音效与音乐盒
src/ui/player.ts      把状态变化变成动画队列（走、快进、倒流、上弦）
src/main.ts           界面、输入、钟面选层、对话框
docs/LEVEL-FORMAT.md  关卡格式、一拍内的结算顺序、如何加新关
```

进度保存在浏览器的 localStorage 里。如果存储不可用（比如隐私模式），游戏照常能玩，只是不保存进度。
